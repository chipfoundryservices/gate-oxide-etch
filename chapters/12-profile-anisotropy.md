# Chapter 12: Profile Control & Anisotropy Mechanisms

## 12.1 Anisotropy Definition

```
Anisotropy = (Vertical Rate - Horizontal Rate) / Vertical Rate
```

**Perfect Anisotropy** = 1.0 (vertical only)
**Perfect Isotropy** = 0.0 (equal all directions)

## 12.2 Achieving High Anisotropy (>0.87)

**Mechanisms**:
1. **Polymer Sidewall Passivation**: 
   - C₄F₈ deposits CFₓ on walls
   - Prevents lateral radical etch
   
2. **Ion Directionality**: 
   - Perpendicular ion impact sputters polymer from bottom
   - Ions have directionality, radicals are random

3. **Low Pressure**: 
   - Longer mean free path → More directional ions
   - Fewer random collisions

## 12.3 Profile Optimization

**Target Profile**: <5° sidewall angle for advanced nodes
**Measurement**: Cross-sectional SEM or AFM
